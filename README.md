# Cultcord

aka. Knucklebones.NET

A fanmade implementation of Cult of the Lamb's minigames for Discord (still a work in progress).

## Features

- Knucklebones

- Devotion (leveling)

- Match requests (either for a specific person or anybody)

- Bot games (by requesting a match with the bot itself)

## Planned features

- Flockade

- Discord activity/website
